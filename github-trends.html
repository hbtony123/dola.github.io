    这份观察怎么来的

    数据只做一件事：量增量

    每天 08:05 抓一次 GitHub 公开 API 快照，用相邻快照的 Star 差值衡量“这段时间涨了多少”，不拿 Star 总量冒充热度。

    观点和数据分开写

    数字由脚本计算、原样可查；写什么、怎么看由编辑判断。判断会错，所以每期都附上当天的数字，欢迎拿数据反驳结论。

    写不出就不发

    当天没有值得写的变化、或者数据不完整时，这一期就不更新，页面保留上一期，而不是凑一篇流水账。
