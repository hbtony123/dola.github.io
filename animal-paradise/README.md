# 🐾 动物乐园 - 纯 CSS 绘制的奇妙世界

一个用纯 CSS 和 JavaScript 创建的单页面网站，展示可爱的动物形象，无需任何图片资源！

## ✨ 特色功能

### 🎨 纯 CSS 绘制的动物
- **三花猫** 🐱 - 三种颜色的可爱猫咪
- **骏马** 🐴 - 奔跑的英姿
- **忠犬** 🐶 - 忠诚的朋友
- **十二生肖** 🐭🐮🐯🐰🐲🐍🐴🐑🐵🐔🐶🐷 - 完整的中国生肖系列

### 🌐 多 API 集成
- **天气信息** - 实时天气（Open-Meteo API）
- **日期时间** - 当前日期和时间
- **每日名言** - 随机名言（Quotable API + 备用列表）
- **生肖运势** - 今日生肖轮播

### 🎯 交互功能
- **自动播放** - 每 5 秒自动切换动物
- **键盘控制** - 使用方向键、空格键和字母键
- **实时刷新** - 一键刷新所有数据
- **分享功能** - 分享到社交媒体或复制链接
- **背景音乐** - 柔和的环境音乐（Web Audio API）
- **PWA 支持** - 可安装到手机主屏幕
- **响应式设计** - 完美适配手机和平板

### 🎵 新增功能（v1.1）
- **环境音乐** - 使用 Web Audio API 生成的柔和和弦音乐
  - 点击右上角音乐按钮 🔇/🎵 开启/关闭
  - 按 `M` 键快速切换
  - 无外部音频文件，纯代码生成
  
- **PWA 应用** - 可安装到手机
  - 支持离线访问
  - 添加到主屏幕
  - 全屏体验
  
- **分享功能** - 一键分享
  - 支持原生分享（手机）
  - 自动复制到剪贴板（桌面）
  - 显示分享成功提示
  
- **背景动画** - 漂浮的 emoji 形状
  - 随机动物表情和符号
  - 柔和的动画效果

## 🎮 操作说明

### 鼠标操作
- 点击 **"下一只动物"** 按钮切换到下一个动物
- 点击 **"自动播放"** 按钮开启/关闭自动切换
- 点击 **"刷新数据"** 按钮更新天气、名言等信息

### 键盘快捷键
- `→` 或 `空格` - 下一只动物
- `←` - 上一只动物
- `R` - 刷新所有数据
- `M` - 开关背景音乐

## 📱 响应式设计

网站自动适配不同屏幕尺寸：
- **桌面端** - 完整布局
- **平板** - 自适应网格
- **手机** - 单列布局，缩放动物图像

## 🛠️ 技术栈

- **HTML5** - 语义化结构
- **CSS3** - 纯 CSS 绘制动物，动画效果
- **JavaScript (ES6+)** - 交互逻辑和 API 调用
- **无外部依赖** - 零图片，零框架

## 🔌 API 集成

### 天气 API
- 使用 Open-Meteo（免费，无需 API 密钥）
- 默认位置：上海（可修改）

### 名言 API
- 使用 Quotable API
- 备用名言列表（当 API 不可用时）

### 日期/时间
- 使用浏览器本地时间
- 时区：Asia/Shanghai

## 🎨 自定义

### 修改位置
编辑 `app.js` 中的 `loadWeather()` 函数：
```javascript
const lat = 你的纬度;
const lon = 你的经度;
```

### 添加新动物
在 `app.js` 的 `animals` 数组中添加新对象：
```javascript
{
  id: 'your-animal',
  name: '动物名称',
  emoji: '🐾',
  description: '动物描述',
  render: () => `你的 CSS HTML`
}
```

### 修改主题颜色
编辑 `styles.css` 中的 CSS 变量：
```css
:root {
  --primary: #你的颜色;
  --secondary: #你的颜色;
  --bg-gradient: linear-gradient(...);
}
```
